# myVPN

Menu-bar клиент для macOS: несколько именованных WireGuard-каналов, ручная таблица маршрутов (как Clash/sing-box), самодиагностика.

Российские сайты — через маршруты `geosite-ru` / `geoip-ru` → `direct`. Домашние сети — CIDR → выбранный канал. Остальной интернет — канал с галкой «по умолчанию». Ключи только на вашем Mac.

## Возможности

- Вкл/Выкл из строки меню (после одноразовой установки системного помощника — без пароля)
- **N каналов** — сам задаёшь имя; один шаблон `.conf` на все
- **Маршруты вручную** — CIDR / rule_set → канал или `direct` (не через AllowedIPs)
- Списки RU (rule-set) с обновлением из меню
- Монтирование NAS по SMB (опционально)
- **Диагностика** — снимок каналов и понятный вердикт
- **Обновление** — из Настройки → Update (GitHub Releases)

## Требования

- macOS 13 или новее
- [sing-box](https://github.com/SagerNet/sing-box) (Homebrew: `brew install sing-box`)
- Один или несколько WireGuard-конфигов

## Установка

Приложение ставится **только из GitHub Releases** (не из исходников).

1. Скачайте **myVPN.app.zip** с [Releases](https://github.com/dimark57/myVPN-mac/releases/latest).
2. Распакуйте в `~/Applications` (или перетащите `myVPN.app` туда).
3. Откройте приложение (иконка в строке меню).
4. При предупреждении Gatekeeper: **Системные настройки → Конфиденциальность и безопасность → Открыть всё же** (пока нет нотаризации Apple).

## Первый запуск

1. В меню: **Установить помощника** (только если не ок) — один раз пароль администратора. Или **Настройки… → System Helper**.
2. **Настройки…** (System Helper / Channels / Routes / Shares / Update)
   - **Channels** — имя, кто default (egress), импорт/вставка `.conf`, автоподнятие после перезагрузки
   - **Routes** — LAN → `direct`, домашние сети → канал home, RU packs → `direct`
   - **Shares** — NAS/DNS, автоподключение NAS
   - **Update** — проверка версии с GitHub Releases
   - **Сохранить**
3. **Обновить RU** (если в маршрутах есть geosite/geoip).
4. **Включить**.

Старые `macbook.conf` / `home.conf` подхватываются автоматически (миграция в `channels[]` + `routes[]`).

## Настройка

| Что | Где |
|-----|-----|
| Каналы | Настройки → Channels |
| Маршруты | Настройки → Routes |
| NAS / DNS | Настройки → Shares |
| Системный помощник | Настройки → System Helper |
| Автоподнятие VPN | Настройки → Channels |
| Авто-NAS | Настройки → Shares |
| Обновление app | Настройки → Update |
| Справка | Справка… |

Ключи: `~/.config/wireguard/`. Топология: `~/.config/myvpn/settings.json` (`channels`, `routes`).

## Обновление

Обновление приложения — **только через релиз на GitHub**:

1. **Авто:** при запуске и каждый час — проверка Releases; если новее — скачивает и ставит сама.
2. **Вручную:** Настройки… → Update → Проверить обновление.

Списки маршрутизации RU — отдельно: **Обновить RU** (это не версия приложения).

## Диагностика

Если интернет «странный» или NAS не виден: **Диагностика**.  
Логи: `~/Library/Logs/myvpn-menubar.log`, `~/.config/myvpn/sing-box.log`.

## Безопасность

- Приватные ключи WireGuard хранятся только локально.
- Пароль NAS — в связке ключей macOS.
- Репозиторий не принимает `.conf` с ключами (см. [SECURITY.md](SECURITY.md)).
