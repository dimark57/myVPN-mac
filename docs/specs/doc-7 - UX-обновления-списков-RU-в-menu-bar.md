# UX обновления списков RU в menu bar

Дополнение к **doc-4 — Menu bar myVPN** и к **doc-2 — Ядро sing-box и CLI myvpn** (§ списки RU).  
Задача: **MYMAC-9**.

Цель: при «Обновить списки RU» пользователь **видит ход и итог**, меню **не глушится целиком**.

## Граница

| Входит | Не входит |
|--------|-----------|
| Индикация прогресса на пункте меню | Клон Happ (подписки, VLESS, магазин) |
| Два именованных списка RU в UI | Новые источники сверх ru-routing-dat / doc-2 |
| Явный успех / ошибка + last-updated | Network Extension (**doc-5**) |
| Меню остаётся usable во время обновления | Полноценный progress-bar widget / отдельное окно Happ |

## Сколько списков

Ровно **два** набора правил (как собирает `myvpn update-rules`):

| Имя в UI | Файлы / смысл |
|----------|----------------|
| **geosite-ru** | домены РФ → `geosite-ru.srs` |
| **geoip-ru** | IP/CIDR РФ → `geoip-ru.srs` |

Каталог: `~/.config/myvpn/rules/`.

## Поведение меню (обязательно)

### Не глушить меню

- Пока идёт `update-rules` (или любая долгая команда): **disabled только текущий пункт**.
- Остальные пункты остаются доступны, если не конфликтуют.
- Нельзя снова выставлять global `busy` на всё меню.
- Клик по пункту **не** закрывает меню (sticky); закрытие — mouse leave (решение CEO).

### Прогресс

Пока пункт занят, title in-place: **`«… — выполняется»`** (без анимации точками `.` / `..` / `...` — отменено CEO 2026-09-07).  
Параллельно: **уведомление** о старте операции и об итоге.

Тот же приём допустим для Вкл/Выкл, NAS, helper.

### Состояние в покое

1. `geosite-ru` — mtime **или** «нет».
2. `geoip-ru` — то же.
3. Опционально «Обновлено: …» = max(mtime).

Источник: mtime `~/.config/myvpn/rules/geosite-ru.srs` и `geoip-ru.srs`.

### Успех и ошибка

| Исход | UI |
|-------|-----|
| Успех | UNNotification «Списки RU обновлены» + даты; пункт снова enabled |
| Ошибка | Уведомление с кратким сообщением; busy снят |

Тихий успех **запрещён**.

## CLI

`myvpn update-rules` — SoT (doc-2). Exit 0 / ≠0; UI читает mtime файлов.

## Приёмка

1. Клик «Обновить списки RU» → на пункте «— выполняется»; остальное меню живо; меню не закрылось от клика.
2. Успех — notify + обновлённые даты.
3. В покое видны geosite-ru и geoip-ru.
4. Сбой сети — ошибка, busy снят.
5. Нет окна «как Happ»; нет global mute.
